# Feature illustration slots

Add the four local custom WebP illustrations here using these exact names:

- `trust-layer.webp` — holographic multilayer shield
- `signal-layer.webp` — intelligent core with flows and connections
- `momentum-layer.webp` — 3D clock with dynamic rings
- `visibility-layer.webp` — holographic dashboard with indicators

Until a file is added, the site keeps its current CSS/DOM spatial illustration as a fallback. The image layer is lazy-loaded, responsive and clipped inside the existing glassmorphism card. Production assets use the standardized 720 × 420 px slot defined by `SpatialIllustration`.
